# Website, ecommerce applications

- Frontend : Angular
- Backend : Spring
- Database : MySQL

## Navigation in the browser

The website is accessible at `http://localhost:4000` with `npm run serve:ssr:frontend`.

### Admin part

The admin part is accessible at `/admin`.
To subscribe as an administrator use `/inscription-admin` or to log in with an administrator account use `/connexion-admin`.

### Use cart

Click on "Ajouter au panier" on products page. Change quantity on cart page or page of a product.
